## 📖 About

Ping Display shows your current server ping and packet loss in a clean HUD, with a rolling graph, colour thresholds, and alert sounds on high-latency spikes.

---

## ✨ Features
<a name="features"></a>

- **Live Ping** — updated every second.
- **Packet Loss %** — displayed alongside ping.
- **Rolling Graph** — 60-second history.
- **Colour Thresholds** — green <50ms, yellow <150ms, red >=150ms.
- **Lag Alert** — sound on spike above threshold.
- **Toggle Key** — quick on/off.

> 🔑 **100% free** — no key system, no linkvertise, no ads.
